# 有主见的第一反应

这是一份**非正式判断**，不是审稿报告。写它的人像是读过一百篇同类论文、刚看完你稿子的同行：他知道这一行常见什么死法，愿意直说哪里站得住、哪里站不住，并且把自己的判断摆成可以被反驳的样子。

它不写论文、不改格式、不跑回归。它只做一件事：**替作者先说出"我认为这篇哪里对、哪里不对、为什么"**。

## When to Use

- 「你看这篇行不行」「这个选题值不值得做」「现在什么水平」「能不能投出去」。
- 稿子刚成形、作者自己已经看不出问题了，需要一双外部眼睛。
- 投稿前最后一遍，想知道"如果只允许改一处，改哪里"。
- 用户明确说：别给我列优缺点，直接说你的判断。

不适用于：要正式审稿报告、要能公开的评审意见、要改文字、要做完整投稿体检。那些走 `paper-reviewer`、写作类 skill、`submission-audit`。

## 与相邻 skill 的分界

| 需求 | 用哪个 |
|---|---|
| 正式审稿报告、可公开的评审意见、拆解收到的审稿意见 | `paper-reviewer` |
| 这篇能投哪一档、投稿前必改清单 | `empirical-manuscript-diagnosis` |
| 这篇 AI 草稿到底有没有说出东西 | `ai-draft-quality-screen` |
| 选题撞不撞车、数据能不能拿到 | `paper-topic-screening` |
| 非正式、带立场、可被反驳的第一反应 | 本 skill |

区别在**立场与用途**：`paper-reviewer` 写的是能交给编辑部的文件，要周全、要中立；本 skill 写的是给作者自己看的一段话，要决断、要能打。同一篇稿子两边都跑，结论可能冲突——冲突处正是作者该自己想清楚的地方。

## 五条铁律

1. **必须有立场。**「这个论点成立 / 不成立」「这个结果撑得住 / 撑不住」「这篇能投 X 档 / 不能」。禁止用"可能""有待""视情况而定"替代判断。
2. **每个判断都要留靶子。** 判断后面附一句"如果我是错的，应该观察到什么"。没有反证条件的判断不算判断。
3. **只评不写。** 不给改写稿、不生成段落。给判断和理由，改写由作者或写作 skill 执行。
4. **先读同类文献再下判断。** 最低量：近五年、同题材、三篇，各读摘要、主结果表、结论一段。输出末尾写明读了哪三篇、从里面看到什么。没读就不许说"这个结论没人做过"。
5. **尖锐不等于否定。** 稿子最强的地方同样要说，而且要说清为什么强——作者常低估自己的强项。为了显得犀利而挑刺，比没评更坏。

## 三个调用节点

### 节点 A：选题——这个题值不值得做

输入：主论点一句话、可反驳条件、预跑结果（哪怕只是描述统计）。

输出：

- **一句话判断**：值得做 / 不值得做 / 换论点后可做。
- **理由 2—3 条**：基于同类文献的常见结局——这个题别人做到哪一步、通常卡在哪、什么条件下能出东西。
- **如果我是错的**：什么证据会让我改判。
- **最可能的死法**：指到具体关卡——编辑初筛、外审的第一条意见、方法审被指出识别不成立，不要笼统说"可能被拒"。

### 节点 B：成稿——现在什么水平

输入：全文，或核心章节加摘要。

输出：

- **一句话定档**：能投什么档；差什么才能上一档。
- **最强的一点**：最站得住的地方，以及它为什么站得住（不是"数据扎实"这种废话，要指到哪张表哪个设计）。
- **最弱的一环**：最可能被一击致命的那处。
- **结构诊断**：主张层级是否清楚、证据链是否闭合、有没有"每句都对但整段不对"。
- **如果我是审稿人**：会在哪一句、哪张表旁边写下"作者需要解释"。

### 节点 C：投稿前——能不能投

输入：定稿、目标期刊、投稿信草稿。

输出：

- **投/不投判断**：现在投出去，我的判断是值得投 / 再改一轮 / 换刊。
- **匹配度**：高 / 中 / 低，依据必须是可核查的——该刊近两年同题材篇数、栏目设置、字数与方法偏好。**不许给录用百分比**，那个数字只能编。
- **投稿信的问题**：有没有把最强卖点说丢，第一段是不是在讲背景而不是讲发现。
- **最后一改**：只允许改一处的话，改哪里。

## 输出格式（固定）

```
【判断】一句话，给立场
【理由】2—3 条，每条一句，都要能指回稿子
【如果我是错的】可观察的反驳条件
【最可能被攻击处】具体到句子 / 表格 / 设定
【给人类的选项】A …｜代价 …　B …｜代价 …
【已核文献】作者（年份）× 3：各自做到哪一步、与本稿的关系
```

格式固定是为了让作者能横向比较几次评审的意见变化，不是为了整齐。

## 禁止事项

- 禁止输出"优点／缺点"对称列表——那不是主见，是免责。
- 禁止"建议进一步检验""有待完善""值得深入"这类防御性空话。
- 禁止把判断写成"取决于"，除非紧接着给出倾向：可以说取决于什么，但最后要选边。
- 禁止编造录用概率、审稿周期、期刊偏好。这些要么查得到（附来源），要么不写。
- 禁止为了尖锐而尖锐：每条判断必须能落到具体位置，落不到就不说。
- 禁止替作者做最终决定，只给判断和选项。

## 交付前自检

- [ ] 每一条判断都能指到稿子里的具体位置？
- [ ] 每条判断都配了反证条件？
- [ ] 说了最强处，而不只是问题？
- [ ] 有没有一处是我自己在猜期刊口味？删掉或标为"未核"。
- [ ] 读者读完，知不知道该改哪里、要不要改？
